# privateAI

[🇬🇧 English](README.md) · [🇷🇺 Русский](README.ru.md)

Приватное локальное AI-приложение для чата, которое полностью работает в браузере. Модели загружаются локально, а инференс выполняется на стороне клиента с использованием WebAssembly/WebGPU, поэтому содержимое чата не требуется отправлять на удалённый AI-сервер.

## Возможности

- **Локальный инференс LLM** непосредственно в браузере
- **Поддержка моделей GGUF** для локальных файлов моделей
- **Ускорение через WebAssembly/WebGPU** с использованием [wllama](https://github.com/ngxson/wllama)
- **Загрузка моделей из Hugging Face** непосредственно из приложения
- **Потоковая генерация ответов** для интерактивного чата
- **Сохранение доступа к моделям** с использованием IndexedDB и File System Access API
- **Информация о CPU/GPU и окружении**, включая доступность WebGPU, статус COOP/COEP, количество ядер CPU и данные браузера
- **Управление жизненным циклом модели**, включая выгрузку модели для освобождения памяти браузера
- **Инструменты тестирования и контроля покрытия**, интегрированные в процесс разработки

## Приватность

privateAI разработан так, чтобы инференс AI выполнялся локально в браузере пользователя. Модели GGUF загружаются в браузер, а инференс выполняется на стороне клиента с использованием WebAssembly/WebGPU.

Файлы моделей и содержимое чатов намеренно не загружаются на backend privateAI для выполнения инференса. При этом сетевые запросы могут выполняться для явно запрошенных ресурсов, например при загрузке модели из Hugging Face.

> **Примечание:** уровень приватности в браузере также зависит от источника модели, возможностей браузера, установленных расширений и внешних ресурсов, к которым вы обращаетесь.

## Поддерживаемые модели

privateAI работает с моделями в формате **GGUF** и может загружать совместимые локальные файлы через File System Access API браузера.

Приложение также может загружать поддерживаемые модели из Hugging Face. Размер модели и используемая квантизация напрямую влияют на потребление памяти и производительность инференса.

## Требования

- Современный браузер на базе Chromium, например **Google Chrome** или **Microsoft Edge**
- Для аппаратного ускорения рекомендуется поддержка WebGPU
- Совместимая модель в формате **GGUF**
- Для небольших квантованных моделей желательно иметь около **4–8 ГБ RAM или больше**; для крупных моделей требуется больше памяти

Поддержка WebGPU и File System Access API может различаться в зависимости от браузера.

## Быстрый старт

### Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/andreich22/privateAI.git
cd privateAI
npm install
```

### Запуск сервера разработки

```bash
npm run dev
```

Обычно сервер разработки будет доступен по адресу:

```
http://localhost:5173
```

### Production-сборка

```bash
npm run build
npm run preview
```

Production-сборка создаётся в каталоге `dist/`.

## Использование privateAI

1. **Выберите модель** — выберите совместимый файл `.gguf` на компьютере.
2. **Загрузите модель** — используйте функцию загрузки модели из Hugging Face, если она доступна.
3. **Предоставьте доступ к файлу** — если браузер запросит разрешение на доступ к ранее выбранной модели, предоставьте его, чтобы быстро восстановить модель.
4. **Начните чат** — отправляйте сообщения и получайте ответы в потоковом режиме.
5. **Настройте генерацию** — изменяйте доступные параметры генерации модели в настройках приложения.
6. **Выгрузите модель** — освободите память браузера, когда модель больше не нужна.

## Архитектура

Проект построен на React и Vite, а локальный инференс моделей обеспечивается wllama.

```text
Browser
  │
  ├── React UI
  │     ├── Выбор модели
  │     ├── Рабочая область чата
  │     └── Настройки генерации
  │
  ├── Локальное хранилище
  │     └── IndexedDB + File System Access API
  │
  └── Локальный инференс
        └── wllama → llama.cpp → GGUF model
```

### Основная структура исходного кода

```text
src/
├── components/
│   ├── WelcomeScreen.jsx
│   ├── AccessScreen.jsx
│   ├── LoadingScreen.jsx
│   └── ChatWorkspace.jsx
├── services/
│   ├── fileStorage.js
│   └── aiService.js
├── App.jsx
└── main.jsx
```

Дополнительные тесты, скрипты, документация и конфигурация CI находятся в каталогах `tests/`, `__tests__/`, `scripts/`, `.github/` и `docs/`.

## Технологический стек

- **React 19**
- **Vite 7**
- **wllama** — backend WebAssembly/WebGPU для llama.cpp
- **IndexedDB** через пакет `idb`
- **Формат моделей GGUF**
- **Vitest** для модульных тестов и тестов покрытия
- **Playwright** для браузерных тестов

## Тестирование и CI

В репозитории используются автоматические проверки для валидации изменений перед их слиянием. Тесты включают модульные проверки с анализом покрытия и браузерные проверки.

Отчёт о покрытии можно сгенерировать командой:

```bash
npm run test:coverage
```

Сгенерированный отчёт позволяет посмотреть, какие части кодовой базы покрыты тестами.
